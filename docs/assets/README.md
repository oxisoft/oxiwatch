# Image assets

Drop the following files into this folder. The README and landing page already
reference them by these exact names.

| File | Used by | Size | Notes |
|------|---------|------|-------|
| `banner.png` | README header | 1280×320 (≈4:1), transparent or dark bg | Logo + tagline "SSH login monitor with Telegram alerts" |
| `og.png` | Social preview (GitHub + landing page OG/Twitter card) | **1280×640** exactly | Brand name + one-line value prop; readable as a thumbnail. Also upload this in repo **Settings → Social preview**. |
| `telegram-alert.png` | README screenshot | ~800px wide | A real Telegram alert + daily report (blur any private IPs/usernames) |
| `favicon.png` | Landing page favicon | 64×64 or 128×128 | Square logo mark |

## Tips for the OG image (biggest SEO/CTR impact)
- Keep text large and high-contrast — it's shown small in search, GitHub cards, and chat previews.
- Include the word **OxiWatch** and a phrase like **"SSH login alerts on Telegram"**.
- Dark background (#0b1020) matches the landing page theme.
- After adding `og.png`, also upload it under GitHub repo **Settings → General → Social preview**.
